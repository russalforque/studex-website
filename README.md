# Studex website

Showcase and download page for [Studex](https://github.com/russalforque/studex), the offline
student companion app.

Plain static HTML and CSS: no build step. Open `index.html` in a browser to preview.

## Publish with GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → `main` / `(root)` → Save.
The site goes live at `https://russalforque.github.io/studex-website/`.

## Download button

The **Download APK** button links to the latest release of the `studex` repo. To publish a
build, create a release there and attach the `.apk` file.
